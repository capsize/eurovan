## 구성

```
[터치 화면 Nova-23P] RJ45 ①──흰색 CAT6 납작 랜선(8가닥)──RS485 아래 포트 [메인 제어 박스]
                     RJ45 ② (비어 있음)                      RS485 위 포트 (비어 있음) ← ESP32 보드 연결 1순위
```

- **통신은 RS485 (확인, 2026-11-25)**: 제어 박스 옆면에 `RS485 X 2` = **RS485 RJ45 포트 2개**. 아래 포트는 화면과 연결, **위 포트는 비어 있다**(금속 핀 8개, 초록·노랑 LED).
- **두 포트는 같은 버스로 추정 (2026-11-25)**: 화면 랜선을 위·아래 어느 포트에 꽂아도 패널이 똑같이 동작했다. 남는 포트가 ESP32 보드 연결 자리다(분배기 불필요). 보드로 엿들어 남는 포트에서 데이터가 들어오면 확정. 만약 조용하면 화면 쪽 포트에 **RJ45 분배기 1:2**를 끼운다.
- **터치 화면**: 표시·입력만 한다. 뒷면에 RJ45 포트 2개(①은 제어 박스와 연결, ②는 비어 있음).
- **메인 제어 박스 "(INTELLI)GENT CONTROL SYSTEM"**(인쇄는 `GRNT`): 실제 릴레이·센서 입력.

### 제어 박스 커넥터

| 커넥터 | 모양 | 상태 | 추정 용도 |
|---|---|---|---|
| RS485 X 2 | RJ45 2개 | 아래 = 화면, **위 = 비어 있음** | 화면 통신 버스 → ESP32 연결 지점 |
| CAN | 4핀 (2×2) | **비어 있음** | 리튬 BMS 등 옵션 장치용. 이 차에서는 쓰지 않음(통신 없음) |
| USART | 4핀 (2×2) | 케이블 연결됨(테이프로 감긴 가는 검정 케이블, 묶음 속으로 들어가 끝 미확인) | 어떤 장치와 시리얼 통신. **전압 확인 전에는 건드리지 않는다** |
| A BOTTON | 다핀 | 케이블 연결됨 | 벽 스위치(버튼) 입력 추정 |
| B / C BOTTON | 다핀 | 비어 있음 | 예비 버튼 입력 |
| SINGAL | 12핀 (2×6) | **비어 있음** | 탱크 센서 등 신호 입력 추정 |
| PWM-MOTOR | 다핀 | 연결됨(빨강·노랑·초록·검정) | 어닝등 PWM이나 모터 출력 |
| DC-OUT | 다핀 | 연결됨 | 12V 출력 |
| AC-OUT | 8핀 | 비어 있음 | 220V 출력 |
| SWITCH-A / B | | | 스위치 입력 |
| AC-INPUT(N/L), DC-INPUT(+, 인쇄는 `INPYT`), ACC, BC1, BC2 | | | 전원 입력 |
| 퓨즈 | FA1~FA4, FM·FP·FD·FB | | 아래 퓨즈 표 |

- **SINGAL이 비어 있고 화면의 청수·오수가 계속 0%** → 탱크 센서가 연결되지 않았을 가능성이 있다. 탱크 잔량이 필요하면 센서 연결부터 확인한다.
- 흰색 랜선 플러그(투명)로 보아 8가닥이 모두 연결돼 있다.

- **Battery Coulometer**(화면 아래 적산계): Juntek **TK15**. 4가닥 선(빨강·검정·초록·노랑)으로 따로 연결된 별도 장치. 패널 통신과 별개다. 아래 [적산계](#적산계-juntek-tk15) 참고.
- **빨간/파란 버튼**: 메인 전원 스위치.
- **설정 화면에 Wi-Fi·블루투스·앱 항목이 없다** → 순정 앱 연동은 어려워 보인다.

- 패킷 분석 후, 스위치를 켤 때 해당 퓨즈 회로에 전원이 나오는지 재서 패킷과 출력 채널을 맞춰 본다.

## RJ45 핀 확인 (측정 대기 중)

### 왜 재나

RJ45 8가닥이 각각 어떤 역할인지 알아내야 ESP32 보드를 안전하게 연결할 수 있다. 제조사 핀 배치는 공개돼 있지 않다.

| 역할 | 하는 일 | 멀티미터 숫자(예상) |
|---|---|---|
| 12V | 전원 | 약 12~14 |
| GND | 0V 기준선 | 0 |
| RS485 A | 데이터 선 ① | 약 2.5~3, 통신할 때 흔들림 |
| RS485 B | 데이터 선 ② (A와 짝) | 약 2~2.5, A보다 조금 낮음 |

- **12V를 보드 A/B 단자에 연결하면 보드가 망가질 수 있다.** 그래서 먼저 잰다.
- A/B를 바꿔 연결하면 고장은 안 나고 데이터만 깨진다.
- 제조사에 핀 배치를 받으면 재지 않아도 된다:
  > 您好，请问 Nova-23P-12V 控制系统主机上 "RS485 X 2" 网口（RJ45）的引脚定义是什么？哪几针是 485 A/B、12V 和 GND？谢谢。

### 측정 방법 (둘 중 하나)

> **주의:** RJ45 핀에 12V가 흐를 수 있다. 노트북·공유기 랜 포트에 절대 꽂지 않는다. 멀티미터는 **V⎓ 20V**에만 두고(Ω·삐 모드 금지), 침이 옆 단자와 동시에 닿지 않게 한다. 플러그 끝 금색 접점(1mm 간격)을 직접 재는 건 어려워서 권하지 않는다(2026-11-25 시도).

**A. RJ45 단자대 케이블 (RJ45 암 → 8핀 나사 단자, 컴스 TB943 구매함, 추천)**

제어 박스 안은 좁아서 수형 어댑터를 꽂아도 재기 어렵다(2026-11-25 확인). 암형 단자대 케이블을 랜선으로 이어 선반 위에서 잰다.

```
제어 박스 남는 RS485 포트 ──랜선──▶ 단자대 케이블 구멍 ── [8][7][6][5][4][3][2][1] 나사 단자
```

- 랜선 1~8번 핀이 단자 1~8번에 **1:1**로 이어진다. 단자 번호는 **오른쪽 끝이 1번**, 왼쪽 끝이 8번.
- 단자 아래 `+ − + −` 표시는 실제 극성과 무관하니 무시한다.
- 검정 침은 **8번 단자 나사**, 빨간 침으로 7→1번을 재서 **단자 번호별로** 적는다.
- 측정 후 그대로 **보드 연결용 변환기**로 쓴다(아래 "보드 연결").
- 일반 명칭: RJ45 단자대 케이블, RJ45 터미널 블록 / 영어 RJ45 female to screw terminal, RJ45 breakout / 중국어 RJ45转接线端子, 网口转端子. TB943은 컴스 제품 번호일 뿐 표준 용어가 아니다. 수형 "RJ45 단자대 어댑터"는 포트에 바로 꽂을 공간이 있을 때만.

**B. 남는 랜선 한쪽을 잘라 쓰기**

1. 화면에 연결된 선이 아닌 남는 랜선의 플러그 한쪽을 자르고 바깥 피복을 5cm 벗긴다.
2. 8가닥을 펼쳐 각 끝을 5mm 벗기고, **구리선끼리 닿지 않게** 부채꼴로 벌려 테이프로 고정한다.
3. 남은 플러그를 제어 박스 남는 RS485 포트에 꽂는다.
4. 검정 침은 갈색(8번)에 고정하고(악어 클립 추천), 빨간 침으로 나머지 7가닥을 재서 **색깔별로** 적는다.
5. 끝나면 플러그를 먼저 뽑고 선 끝을 테이프로 감는다.
- 납작 랜선은 색이 표준과 다를 수 있다. 투명 플러그를 금색 접점 위·걸쇠 아래로 들고 왼쪽부터 색 순서를 확인한다.

### 판정 방법

1. 12~14 → 12V, 0 → GND(검정 침과 같은 선).
2. 2~3 근처이고 **화면 버튼을 누를 때 흔들리는** 두 선 → RS485 쌍(높은 쪽이 A).
3. 모든 숫자가 0이면 검정 침을 다른 핀(예: 4번)으로 옮겨 다시 잰다.
4. 숫자 앞 `-`도 그대로 적는다.
5. RS485 쌍이 두 개 나오면 보드(RS485 1채널)로 차례로 엿들어 화면↔제어 박스가 대화하는 쌍을 찾는다.

### 보드 연결 (판정 후)

보드 전원도 **같은 랜선의 12V 핀**에서 받는다(결정 2026-11-26).

**근거 (2026-11-26 관찰):** 화면 뒤 랜선을 뽑으면 화면이 꺼지고, 다시 꽂으면 켜진다 → 화면은 **이 랜선으로 전원을 받는다.** RJ45에 전원 핀과 GND 핀이 있다는 뜻이다. 랜선을 제어 박스 위쪽 포트로 옮겨도 화면이 똑같이 동작했으므로 **빈 포트에도 같은 전원이 나온다.**

확인할 것:
- **전압:** 보통 12V지만 화면용 5V일 수도 있다. 12~14V면 그대로 V+에 쓴다. 5V면 V+(7~36V)에는 부족하니 보드 USB-C 5V 쪽 급전을 따로 찾는다.
- **전류 여유:** 제어 박스가 이 포트에 화면 몫만 내줄 수도 있다. 화면 + 보드 합쳐 0.5A 안팎이라 대개 괜찮지만, 보드를 처음 연결하면 **화면이 깜빡이거나 꺼지지 않는지** 확인한다.
- **퓨즈 1A 필수:** 보드 쪽 합선 시 같은 전원을 쓰는 화면까지 꺼질 수 있다. 퓨즈가 먼저 끊어지게 한다.
- 측정에서 12V 핀이 여러 개 나오면 화면이 그 핀들로 전원을 받는 것이다. 랜선 하나로 통신과 전원을 같이 받고, 메인 스위치에 맞춰 보드도 켜지고 꺼진다.

```
단자대 케이블 단자          Waveshare 보드 나사 단자
12V  ──[퓨즈 1A]──────────→  V+ (전원 입력 7~36V)
GND  ─────────────────────→  GND (전원)
RS485 A  ─────────────────→  A
RS485 B  ─────────────────→  B
GND  ─────────────────────→  RS485 GND (절연형이라 따로 표시돼 있으면 같이 잇는다)
※ 12V는 절대 A/B에 연결 금지
```

- 보드 소비 0.1~0.3A, 랜선 한 가닥은 약 0.5A까지 무난하다. 12V 핀이 2개면 둘 다 쓴다.
- 퓨즈: "인라인 퓨즈 홀더 미니 블레이드" + **1A** 퓨즈. 보드 쪽 문제가 제어 박스·화면 전원에 번지지 않게 한다.
- USB-C와 12V를 동시에 꽂아도 되는지는 Waveshare 위키에서 확인. 확인 전엔 하나만.
- 측정에서 12V 핀이 없으면 대안:

| 대안 | 메인 스위치 끄면 | 비고 |
|---|---|---|
| USB-C (노트북·패널 USB·보조배터리) | 꺼짐 | 시험·펌웨어 올릴 때 |
| 시거잭·제어 박스 남는 퓨즈 출력 | 꺼짐 | 플러그나 퓨즈 탭 |
| 배터리 직결 (퓨즈 1A) | 안 꺼짐 | 메인을 꺼도 TK15 감시가 필요할 때 |

### ESP32로 읽기

- 표시부 뒤 4가닥 선이 측정 장치(션트)와 표시부를 잇는다. 보통 빨강·검정 = 전원, 초록·노랑 = 데이터.
- 같은 회사 KG-F/KH-F 시리즈는 이 선이 UART(TTL)이고, 표시부가 묻고 측정 장치가 답하는 구조라 ESP32는 답만 엿들으면 된다: [esphome-junctek_khf](https://github.com/gianfrdp/esphome-junctek_khf).
- TK15의 공개 분석 자료는 없다. 포럼에는 데이터에 CRC가 붙어 있다는 언급만 있다: [HA 포럼 TK15 스레드](https://community.home-assistant.io/t/esphome-solar-system-any-suggestions-for-tk15-coulomb-meter-battery-monitor-integration/323930).
- 연결: Waveshare 보드의 **확장 포트(GPIO)**에 UART RX로 연결한다(보드에 들어 있는 JST→점퍼핀 케이블 사용). 패널(CAN)과 적산계(UART)를 보드 하나로 읽는다.
- **먼저 초록·노랑 선 전압을 잰다.** 3.3V/5V 신호면 분압 저항이나 레벨 변환기를 거쳐 연결하고, 12V 근처면 ESP32에 바로 연결하지 않는다.
- 표시부 뒤 커넥터가 뽑히는 구조면 같은 커넥터로 Y자 분기를 만든다.
