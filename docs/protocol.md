## 구성

```
[터치 화면 Nova-23P] RJ45 ①──흰색 납작 랜선──RJ45 [메인 제어 박스 "SYSTEM"]
                     RJ45 ② (비어 있음) ← ESP32 보드 연결 후보
```

- **터치 화면**: 표시·입력만 한다. 뒷면에 RJ45 포트 2개(①은 제어 박스와 연결, ②는 비어 있음). 버스를 잇는(데이지 체인) 구조이거나 옵션 Wi-Fi·앱 모듈 자리로 추정한다.
- **메인 제어 박스 "SYSTEM"**: 실제 릴레이·센서 입력. 오른쪽 옆면 RJ45 포트로 화면과 연결된다.
  - 커넥터: PWM-MOTOR, AC-OUT, DC-OUT, SWITCH-A, SWITCH-B, AC-INPUT(N/L), DC-INPUT(+), ACC, BC1, BC2, B/C BOTTON
  - 퓨즈: FA1~FA3, FM1, FP2/FP4, FD5/FP8, FD6, FB1, FB2
- **Battery Coulometer**(화면 아래 배터리 잔량계): 4가닥 선(빨강·검정·초록·노랑)으로 따로 연결된 별도 장치. 패널 통신과 별개로 보인다.
- **빨간/파란 버튼**: 메인 전원 스위치.
- **설정 화면에 Wi-Fi·블루투스·앱 항목이 없다** → 순정 앱 연동은 어려워 보인다.

## 빈 RJ45 포트 핀 확인 순서

필요한 것: RJ45 단자대 어댑터("RJ45 to screw terminal"), 짧은 꼬임 랜선(CAT5e 이상), 멀티미터.

1. 빈 포트 ②에 랜선 → RJ45 단자대 어댑터를 연결한다.
2. 멀티미터로 단자 1~8번을 하나씩 GND와 비교해 잰다.
   - 약 12~14V → 전원
   - 0V → GND
   - 두 핀이 모두 약 2.5V → **CAN-H / CAN-L** (H가 약간 높다)
   - 두 핀 사이에 차등 전압 → RS485 A/B
3. 아래 표에 적고, CAN 두 핀을 Waveshare 보드 CANH/CANL에, GND를 GND에 연결한다.
4. 포트 ②가 버스가 아니면(전압이 다 0V 등), 제어 박스 쪽 RJ45에 **RJ45 분배기 1:2**를 끼워 분기한다.

> **주의:** 이 RJ45 포트에는 12V가 흐를 수 있다. 노트북·공유기 랜 포트에 절대 꽂지 않는다.
