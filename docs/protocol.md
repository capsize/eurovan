# Nova-23P-12V 프로토콜 기록

## 패널 구성 (2026-11 사진 기준)

- 터치 화면(Nova-23P)은 표시·입력만 하고, 실제 스위치는 별도 메인 제어 박스(릴레이·센서 입력)가 켜고 끄는 구조로 추정한다.
- 화면 아래 **Battery Coulometer**(배터리 잔량계)는 별도 장치로 보인다.
- 빨간 버튼은 메인 전원 스위치로 보인다.

```
[터치 화면 Nova-23P] ── 통신선(CAN 추정) ── [메인 제어 박스]
                                               ├ 조명·펌프·냉장고·TV·USB
                                               ├ 인버터·충전기
                                               └ 청수·오수 탱크 센서
```

## 확인할 것

- [ ] 화면 설정(⚙) 메뉴에 Wi-Fi/블루투스/APP 항목이 있는지
- [ ] 메인 제어 박스 위치·모델명·커넥터
- [ ] 화면 뒤 커넥터 선 수와 통신선
