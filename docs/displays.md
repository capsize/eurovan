### 대시보드를 어디에 두나

| 방법 | 필요한 것 | 모양 | 기록·그래프 |
|---|---|---|---|
| ① ESPHome 기본 웹 화면 | 보드만 | 목록 나열 | ❌ |
| **② 보드에 직접 만든 페이지** (시작) | 보드만 | 시안처럼 자유롭게. ESPHome `web_server`의 `/events` 실시간 값을 받아 그림 | 간단한 것만 |
| ③ Home Assistant | 라즈베리파이 등 + 공유기 | 가장 유연 | ✅ 장기 기록, 원격, 알림 |

②로 시작하고, 기록·원격이 필요해지면 ③으로 넓힌다. 보드 설정은 그대로 쓴다.

## 화면별 정리

### Nova-23P 패널 화면: 불가

제조사 전용 화면이라 브라우저·Wi-Fi가 없고 펌웨어 변경 방법도 공개돼 있지 않다.

### 삼성 M5 27인치 스마트모니터 (TV)

- 내장 **인터넷(브라우저) 앱**으로 보드 웹 화면을 연다. 리모컨 방향키로 조작(시안의 스위치는 방향키 이동 지원).
- 블루투스 마우스·키보드를 붙이면 편하다.
- TV 퓨즈(FD3) 출력에 달려 있어 패널에서 TV를 켜야 보인다.
- 나중에 Home Assistant ↔ SmartThings 연동으로 리모컨 제어도 가능(맨 나중 단계).

### 공유기 (LTE 라우터 추천)

모니터를 보드 Wi-Fi(AP)에 붙이면 인터넷이 끊긴다. 공유기에 보드·모니터·아이폰을 모두 붙이면 해결된다.

| 공유기 | 제어 | 모니터 인터넷 |
|---|---|---|
| **LTE 라우터** (USIM) | ✅ | ✅ 어디서나 |
| 일반 공유기 + 휴대폰 테더링 | ✅ | ✅ 휴대폰 있을 때만 |
| 일반 공유기만 | ✅ | ❌ |
| 아이폰 핫스팟 | ✅ | ✅ 아이폰 있을 때만 |

- 보드는 공유기 Wi-Fi에 붙게 바꾸고, 자체 AP는 예비로 남긴다.
- 공유기에서 보드 **IP 고정**(예: `192.168.0.50`). 삼성 브라우저는 `.local` 주소를 못 찾을 수 있다.
- LTE 라우터는 밖에서 아이폰 원격 제어할 때도 필요하다. 12V·USB 전원 제품이 설치하기 좋다.

#### 구매한 공유기: GL.iNet GL-MT3000 (Beryl AX)

- Wi-Fi 6 여행용 공유기, OpenWrt 기반. **LTE(유심) 내장은 없다.**
- **전원:** USB-C 5V 3A → 12V→USB-C PD 충전기(15W 이상)를 상시 전원에 연결.
- **인터넷 받는 법:**

| 방법 | 언제 |
|---|---|
| 아이폰 USB 테더링 | 사람이 차에 있을 때 |
| 리피터(캠핑장·카페 Wi-Fi) | Wi-Fi 있는 곳 |
| USB LTE 동글(유심) | 늘 인터넷 → 원격 제어·알림. 지원 모델 목록 확인 |
| 유심 넣은 남는 폰(예: SE3) USB 테더링 | 동글 대신 |

- **보드 IP 고정:** 관리 화면(192.168.8.1) → Clients에서 보드에 고정 IP 예약. 위 예시 `192.168.0.50` 대신 이 공유기 대역(`192.168.8.x`)을 쓴다.
- **밖에서 접속:** 펌웨어에 Tailscale·WireGuard가 들어 있다. 공유기에 Tailscale을 켜고 아이폰에도 깔면 포트 개방 없이 보드 화면에 접속(공유기에 인터넷이 있을 때).
- 보드·M5 모니터·아이폰·WLED 컨트롤러를 모두 이 Wi-Fi에 붙인다. 보드 자체 AP는 예비.

### 패널 옆 7인치 터치 화면 (나중에)

**Waveshare ESP32-S3-Touch-LCD-7** — 7인치 800×480 정전식 터치, RS485·CAN 단자 포함.

- 제품: <https://www.waveshare.com/esp32-s3-touch-lcd-7.htm>
- 위키: <https://www.waveshare.com/wiki/ESP32-S3-Touch-LCD-7>
- 핀(공식 문서): RS485 TX GPIO15 / RX GPIO16(방향 자동), CAN TX GPIO20 / RX GPIO19(TJA1051, PH2.0 2핀).
- 비슷한 **-7B**는 핀 배치가 다를 수 있다(GPIO16이 UART로 표기). 정확히 **-7**인지 확인.
- 알리 옵션: Without Touch(X) / With Touch Function / **Touch-LCD-7-U**(외장 안테나로 추정, 사진에 안테나 단자 있으면 추천). 2026-11 기준 약 ₩52,600.
- 알리 "배터리 포함"은 AI 요약이라 믿지 않는다. 보통 단자만 있다.
- 전원은 USB-C 5V가 기본 → 12V→USB-C 변환기 사용. 12V 직접 입력 여부는 위키에서 확인.
- 화면은 ESPHome `lvgl`로 새로 그린다(웹 시안을 그대로 쓰지 못함).
- 주문한 보드는 RS485·CAN이 절연형이다. 터치 화면은 절연형이라는 설명을 못 찾았다. 그래서 **버스 연결은 지금 보드가 맡고**, 터치 화면은 Wi-Fi로 연결한 표시·조작 전용으로 쓴다(버스에 장치 두 개를 물리지 않음).

### 안 쓰는 아이폰 SE3 (상태판 겸 보안 카메라)

1. 패널 옆에 거치대 고정, 12V USB 포트에 라이트닝 케이블 상시 연결.
2. Safari로 보드 주소 → **공유 → 홈 화면에 추가**(전체 화면).
3. 설정 → 디스플레이 및 밝기 → 자동 잠금 **안 함**.
4. 설정 → 손쉬운 사용 → **사용법 유도** 켜고, 대시보드에서 측면 버튼 3번 → 화면 고정.

- 4.7인치라 시안이 빽빽하다. **가로 화면에 배터리·탱크·주요 스위치만** 크게 보이는 전용 화면을 만든다.
- **여름 열 주의:** 상시 충전 + 밀폐 차량 → 배터리 부풂 위험. 설정 → 배터리 → **충전 최적화** 켜기, 여름 장기 주차 땐 케이블 빼거나 집에 둔다. 나중에 ESP32로 USB 출력을 제어하면 30~80%만 충전하게 자동화할 수 있다.
- 겸용: Alfred 같은 앱으로 **실내 보안 카메라**(LTE 라우터 있으면 밖에서 확인, 움직임 알림).

## 추천 순서

1. 엿듣기로 패널 상태 항목 확보
2. 보드에 대시보드 페이지(②) → 아이폰·M5 모니터·SE3로 보기
3. LTE 라우터 추가 → 인터넷 + 원격
4. 필요하면 Home Assistant(③), 패널 옆 터치 화면
