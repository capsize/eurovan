# 스마트 조명 추가 (LED 스트립)

패널의 조명1·2·3, 천장등, 어닝등은 RS485로 제어할 예정이다. 이 문서는 **새로 다는 조명** 이야기다.

## 방식 비교

| 방식 | 알리 검색어 | 보드와 연결 | 장점 | 주의 |
|---|---|---|---|---|
| **① WLED 컨트롤러 + 12V 주소형 스트립** (선택) | `GLEDOPTO WLED ESP32`, `WS2815 12V LED strip` | Wi-Fi | 보드 배선 없음, 색·밝기·효과, 아이폰 앱 | 컨트롤러가 12V·WS2815 지원하는지 확인 |
| ② 단색 12V 스트립/COB + MOSFET 모듈 | `D4184 MOSFET module`, `12V COB LED strip warm white` | 보드 GPIO 1개 + GND | 싸고 단순, ESPHome `monochromatic`로 밝기 | IRF520 모듈은 3.3V로 완전히 안 켜짐 → D4184 같은 로직 레벨. 정전류 드라이버 조명은 디밍 불가 |
| ③ 투야 Wi-Fi 전구 | — | — | — | 220V 소켓, 클라우드 의존 → 비추천 |

①을 고른 이유:

- 컨트롤러 안에 ESP32 + WLED(오픈소스 펌웨어)가 들어 있어 보드의 ESPHome에서 Wi-Fi로 켜고 끈다 → [슬라이드 도어 전등](door-light.md)에도 쓸 수 있다.
- 주문한 보드는 남는 GPIO가 적을 수 있는데, ①은 GPIO가 필요 없다.
- WS2815는 12V이고 예비 데이터선이 있어 LED 하나가 고장 나도 뒤쪽이 켜진다.

## 살 것

| 품목 | 확인할 것 |
|---|---|
| GLEDOPTO WLED 컨트롤러 (컨트롤러만 파는 상품) | **ESP32 옵션**(ESP8266 말고), 입력 전압에 **12V 포함**(보통 DC 5~24V), 출력 전류. 마이크(음악 반응)는 선택 |
| LED 스트립 `WS2815 12V` | m당 LED 수, 길이, 방수(실내 IP30, 습기 걱정되면 IP65) |
| 인라인 퓨즈 홀더 + 퓨즈 | 스트립 소비전력보다 조금 크게(대략 m당 0.5~1A, 보통 5A) |
| 링 단자, 전선 | 5A 이하면 0.75~1.25mm²(18~16AWG), 빨강 + / 검정 − |
| 3핀 JST 커넥터 | 컨트롤러 ↔ 스트립 |

## 전원

스트립 전원은 **컨트롤러를 거쳐** 들어간다(컨트롤러 출력 = 12V·데이터·GND 3가닥). 차량에서 끌어올 전원은 **컨트롤러 입력 12V 하나**뿐이다.

```
DC-INPUT + ──[인라인 퓨즈 5A]── 빨강 ──→ 컨트롤러 IN +
제어 박스 −  ─────────────────── 검정 ──→ 컨트롤러 IN −
컨트롤러 OUT (12V·DATA·GND) ──→ WS2815 스트립
컨트롤러 ⇄ Wi-Fi ⇄ ESP32 보드(ESPHome)
```

### 어디서 12V를 받나

제어 박스에는 **빈 퓨즈 자리가 없다**(→ [protocol.md 퓨즈 자리](protocol.md#퓨즈-자리-2026-11-26-사진)).

| 위치 | 결과 | 판단 |
|---|---|---|
| **`DC-INPUT +` 볼트 단자에 링 단자 추가 + 인라인 퓨즈** | 늘 켜짐 → Wi-Fi 제어·도어 연동 가능 | ✅ 추천 |
| FA1~FA4(5A, SWITCH-A·B 옆)에 퓨즈 탭 | FA1 측정 0V(평소 출력 꺼짐) | ❌ |
| 표시 없는 5A 퓨즈(FM1, FD2)에 퓨즈 탭 | 먼저 측정해서 상시 회로일 때만 | 측정 후 |
| FB1·FB2 | 화면(RJ45) 전원일 가능성 | ❌ 건드리지 않기 |
| 패널 조명 채널(조명1 등) | 패널에서 끄면 컨트롤러도 꺼져 Wi-Fi 제어 불가 | 패널로만 쓸 거면 가능 |
| 시거잭·USB | 대개 5V, 전류 부족 | ❌ |

- **−선은 제어 박스 `−` 단자**에 연결한다. 배터리 − 단자에 바로 연결하면 TK15 션트를 거치지 않아 조명 소비가 배터리 표시에 안 잡힌다.
- `DC-INPUT +`가 메인 스위치 뒤쪽이면 메인을 끌 때 조명도 꺼진다(대기 1W 안팎이라 켜 둬도 부담은 작음).
- 작업 전 **메인 스위치 끄기**, 볼트는 단단히 조이기.

### 퓨즈 탭을 쓸 경우

1. 퓨즈 크기 확인(일반·미니·로우프로파일) → 알리 `fuse tap` + 크기.
2. 아래 칸에 원래 퓨즈, 위 칸에 새 퓨즈(3~5A).
3. **방향:** 멀티미터로 전압이 걸리는 다리(입력 쪽)를 확인하고, 탭 다리를 그쪽에 꽂는다. 반대로 꽂으면 원래 퓨즈가 보호하지 못한다.
4. 상시 회로인지는 [protocol.md 측정 방법](protocol.md#표시-없는-5a-퓨즈-확인-방법)으로 먼저 확인.

### 연결 후

1. 메인 스위치 켜고 컨트롤러 입력에서 12V 확인.
2. 스트립 연결, WLED 앱(아이폰)으로 와이파이 설정 → 공유기 Wi-Fi에 연결하고 IP 고정.
3. 3m 넘게 길면 끝이 어두워지거나 색이 변할 수 있다 → 반대쪽 끝에 12V를 한 번 더 넣는다(power injection).

## ESPHome에서 켜기 (초안)

WLED는 HTTP JSON API를 제공한다. 보드에서 `http_request`로 켜고 끈다.

```yaml
http_request:

script:
  - id: strip_on
    then:
      - http_request.post:
          url: http://192.168.0.60/json/state
          json:
            "on": "true"
            "bri": "180"
  - id: strip_off
    then:
      - http_request.post:
          url: http://192.168.0.60/json/state
          json:
            "on": "false"
```

`192.168.0.60`은 예시. 공유기에서 컨트롤러 IP를 고정한 뒤 바꾼다. 슬라이드 도어 자동화에서는 패널 조명 대신(또는 같이) `script.execute: strip_on`을 부르면 된다.

## 순서

1. 넣을 위치·길이 정하기(예: 천장 둘레, 발밑) → 스트립 길이·퓨즈 용량 계산
2. 컨트롤러(ESP32, 12V)·스트립(WS2815 12V)·인라인 퓨즈·링 단자 주문
3. `DC-INPUT +`에서 퓨즈 달아 컨트롤러 전원 연결
4. WLED 앱으로 설정 → ESPHome에 연결
