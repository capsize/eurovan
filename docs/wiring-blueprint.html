확인된 것과 남은 것

  • 확인 위·아래 RS485 포트는 병렬이라 분기 없이 위 포트에 꽂는다.
  • 확인 화면 전원 버튼을 꺼도 12V 유지, 메인 스위치를 끄면 보드도 꺼진다.
  • 확인 TK15 4선은 USART가 아니라 배터리 쪽 션트로 내려간다.
  • 남음 A/B는 전압 차가 0.11V뿐이라 추정이다. 데이터가 깨지면 1·2번을 바꾼다.
  • 남음 USART에 연결된 장치, TK15 션트 위치.
  • 주의 6·7·8번(12V)은 A/B 단자에 절대 연결하지 않는다.
